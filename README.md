# うまプロ 売上（毎日）

どてっぱん全12店の前日売上を毎朝ひろって、今月と年間の着地、5億達成のペースを出すサイト。

```
ダイニー(11店 日別) ┐
blayn(なんば 日別)  ├→ .cache/raw.json → build.py → .cache/payload.json → encrypt.mjs → docs/data/payload.json
MPS(請求 月別/店別) ┘                                    (円入り・非公開)      (合言葉で暗号化)
```

## 見られること

- **前日の売上**（全店合計と店別・いつもの同じ曜日との比較）
- **5億達成のペース** … 今日までに積み上がっているべき額との差、残り日数で1日あたりいくら必要か
- **今月の着地** と **年間の着地（うまプロ）**
- 「くわしく見る」を押すと MPS・月別・店別・前提

## 毎朝の自動更新

`~/Library/LaunchAgents/com.umapro.daily.plist` が毎朝 **9:05** に `run.sh` を叩く。
専用のブラウザプロファイル `.profile` を使うので、出数ダッシュボード(9:05)や売上予報(9:40)とぶつからない。

手で動かすとき:

```bash
~/umapro-daily/run.sh
```

ログインが切れたとき（ダイニー／blayn／MPS のどれでも）:

```bash
node ~/umapro-daily/scripts/browser.mjs
```

3つタブが開くので、切れているものだけログインし直してウィンドウを閉じる。
**閉じないと翌朝の自動取得がプロファイルを掴めない。**

## 決めごと

- 売上は**税込**。ダイニーは画面が税抜表示だが API の税込値を使う
- 2026年7月から全店10%値上げ。6月以前の実績は ×1.10 して価格を揃えてから水準を推定する
- 本部売上 ＝ 38%店×0.38 ＋ 5%店×0.05 ＋ 前橋(直営)の売上全額 ＋ MPS内部請求
- MPSは**前橋を除く11店**。直営は本部が本部に請求する内部取引なので外す
- 石山駅前・日吉駅前は2026年ロイヤリティ10%が未収（28%のみ）、門前仲町は7月売上ぶんから33%
- 料率・目標・ウマチャの金額・祝日は `config.json` にまとめてある

## 公開と合言葉

GitHub Pages は公開なので、**金額は AES-GCM で暗号化**して置いている（合言葉なしでは読めない）。
合言葉は `.env` の `PASSPHRASE`（コミットしない）。変えるときは `.env` を書き換えて `run.sh` を回す。

`.cache/` と `.env` と `.profile/` は絶対にコミットしない。
